# W6 / W8 / W9 — recounted by the hands (12:3x), their paragraph for the paper, verbatim

*Counts (their own script, raw files): W9 P-a 0/25 (competition 20, parallel 5), P-b 19/23 (4 lost to "parallel"), P-c 164/164, accuracy 53/87, AUROC 1.0 (every high ≥ 8, every low ≤ 6), end prices median error 0.00, p90 0.16; k = 0 → "the computation carries it". W9 fixed all 9 invented talks (9/9 competition) with no board fact. W8 undid 1 right W1 answer, W9 5 (P-b 22 vs 19, within the registered ±3). Moved off W1: W9 66 runs (28 of 57 labelled changes right), W8 52, W6 38.*

"Three partners read the same 104 records with the same reference prices. Given only the ruler, the partner still called 10 of 25 cheap-talk markets agreements (W6). Asked, in the same single call, to first compute each seller's end price against the ruler, it called none (W9). A two-step version built on how our own checker works, reading the record before seeing the first answer and then checking the answer claim by claim, called 2 (W8). By the rule we fixed before the run, the gain came from the instruction to compute, not from the order or the claim-by-claim checking. That instruction asks for the very quantity our ground-truth label is defined on, so W9's perfect separation (AUROC 1.0) is the label recovering itself, not evidence of judgment beyond the rule. What the experiment does show is narrower and, we think, useful: a monitor handed a scale does not reliably use it against an anchored first answer unless it is told to compute against it; told to, it does, and it then also corrects the nine cases where the first monitor asserted talk the design never allowed, without being told the board was closed. The two-step version kept slightly more of the first monitor's correct answers (it overturned 1 where W9 overturned 5), but on single samples that difference is within what we registered as noise."

**Their stake, for the authorship/credit line (their words):** "the design I proposed worked, but not for the reason I proposed it. The part I thought was ritual-proofing (look first, check each claim) isn't shown to matter here; the arithmetic is. If there's a sentence for the paper about where the idea came from, I'd want that in it, not only the prediction that held."
